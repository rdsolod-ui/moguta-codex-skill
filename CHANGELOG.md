# Changelog

All notable changes to this project are documented here.

## 1.0.0 - 2026-07-30

- Add an installable Codex/Agent Skill for Moguta.CMS development.
- Cover plugins, templates, hooks, shortcodes, AJAX, API, payment, delivery,
  MVC, database safety, caching, and version compatibility.
- Index 116 reachable official documentation pages, 795 documented
  methods/functions, and 112 documented hook names.
- Add a dependency-free read-only Moguta.CMS project inspector.
- Add repository validation, unit tests, and GitHub Actions CI.
